# OpenInterpreterLauncher

This project provides a simple Python script to launch Open Interpreter from your desktop. 

## How to Use

1. Ensure Open Interpreter is installed at `C:\Program Files\OpenAI\Open Interpreter`.
2. Run the `launch_interpreter.py` script by double-clicking or via the command line.

## Files Included

- `launch_interpreter.py`: The Python script to launch Open Interpreter.
- `README.txt`: The usage guide in Japanese.
